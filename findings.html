02 / THE TARGETRETROSPECTIVE, NOT A PREDICTION

One flight closer
to end-of-life.

Every audited flight follows the same countdown convention.

RUL = final cycle − current cycle

A final observed cycle of 100 and a current cycle of 1 gives RUL 99. RUL stays constant within each flight and reaches zero on the final cycle.

The final lifetime is known retrospectively. Giving it to a model as an input would leak the answer.

03 / OPERATING CONDITIONS & SIGNALSCONTEXT CHANGES THE READING

An engine doesn’t
fly in one condition.

Altitude, Mach, throttle, and temperature change within a flight. Sensor changes can reflect those changes as well as degradation.

THE GENERALIZATION QUESTION

DS02’s test flights go beyond its development classes.

All six development engines are long-flight class 3. The test set also includes short-flight class 1 and medium-flight class 2. This is a coverage difference to plan for, not a measured model failure.

INPUT CANDIDATES

18 physical channels

4 operating conditions + 14 measured sensor channels. “Measured” describes the simulator channel type; engine responses are simulated.

KEEP THE ROLES CLEAR

47 stored ≠ 47 predictors

Following the lecturer’s Dataset Scales slides 3–4 and feature-table notebook. Storage dtype and statistical meaning are separate. Discrete/continuous is also separate from measurement scale.

05 / FROM UNDERSTANDING TO PREPARATIONPROPOSED NEXT STEPS

Build on what
we can explain.

Start with DS01. Define when a prediction is made. Preserve engines and chronology. Then establish a baseline.

Keep the split honest

Use separate development engines for validation and fit preprocessing on training engines only. This EDA exposed test structure and labels; avoid tuning to those test results.

Make the features defensible

Consider current-flight summaries from W + X_s. Exclude future cycles, known final lifetimes, true RUL, and hidden simulator health.

Measure later

MAE and RMSE will follow trained-model evaluation. There are no model scores, measured savings, or operational aviation claims yet.
